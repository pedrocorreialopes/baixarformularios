# 📦 Glipearte — Central de Formulários ECT / Correios

## 🎯 Objetivo
Página web estática que centraliza todos os formulários e documentos utilizados pela **Glipearte Pegue e Monte** para operações postais (ECT/Correios) e contratos de locação de kits artesanais.

---

## ✅ Funcionalidades Implementadas

- **Listagem completa** de 16 documentos PDF organizados por categoria
- **Busca em tempo real** por nome, descrição e tags (com normalização de acentos)
- **Filtro por abas** (Todos / Declarações / Endereçadores / ECT·Correios / Contratos / Outros)
- **Botão Visualizar** — abre o PDF no navegador (nova aba)
- **Botão Baixar** — faz o download direto com nome correto
- **Toast notification** ao iniciar um download
- **Botão "Voltar ao topo"** flutuante
- **Design responsivo** — funciona em mobile e desktop
- **Acessibilidade** — ARIA labels, skip-link, roles semânticos

---

## 📂 Categorias de Documentos

| Categoria        | Documentos |
|-----------------|-----------|
| Declarações      | Declaração de Conteúdo, Declaração Editável, Internacional, Estudo |
| Endereçadores    | A4 Oficial, Editável (v1 e v2), + Comprovante (2 versões) |
| ECT / Correios   | Fechamento Autorizado, Etiquetas Raio-X, Autorização de Retirada |
| Contratos        | Pegue e Monte (v1 e v2), Mini Kit |
| Outros           | Telegrama, Telegrama Editável |

---

## 🗂️ Estrutura do Projeto

```
index.html    ← página principal (tudo em arquivo único)
README.md     ← documentação
```

---

## 🚀 Como usar

1. Abra `index.html` no navegador  
2. Use a barra de busca no cabeçalho para localizar documentos  
3. Filtre por categoria usando as abas  
4. Clique em **Visualizar** ou **Baixar**
